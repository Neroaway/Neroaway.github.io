## 为什么读这篇论文

**演示内容：这不是一篇真实论文的总结。** 我用一个虚构案例来展示如何把问题、证据和自己的理解分开记录。它不对应任何真实作者，也没有实验成绩。

读论文时，我希望先回答两个问题：作者到底试图改变什么？什么证据能支持这种改变？

## 核心问题

假设有一个练习任务：从一组候选解释中选择最符合观察的解释。这个案例关心的不是“解释听起来是否合理”，而是“解释能否对应可检查的证据”。

## 方法与关键直觉

这个虚构方法先列出候选解释，再逐条匹配证据，最后输出解释与证据之间的对应关系。这里的公式仅用于演示数学排版：

$$
s(h)=\sum_{i=1}^{n} w_i\,e_i(h),\qquad \sum_{i=1}^{n}w_i=1.
$$

其中 $h$ 是候选解释，$e_i(h)$ 是演示性证据评分。**没有定义实际数据集，也没有进行估计。**

![从阅读到提问的演示流程，无实验数据](/images/reading-loop.svg)

下面的代码仅演示语法高亮，是一个手工设定分数的玩具例子：

```python
# 演示代码：分数为手工指定，不是论文实验结果。
def score(evidence, weights):
    return sum(value * weight for value, weight in zip(evidence, weights))

example = score([1.0, 0.0], [0.5, 0.5])
print(example)
```

## 优点和局限

这个笔记结构的优点是：我可以追溯每一条判断来自哪里。局限是：结构完整不代表理解正确，仍需回到原文、代码与实际实验。
